一滴水被拉开，再凝回一滴

灵动岛的轮廓有液体的牵引、张力和回弹感。只有黑色轮廓参与融合与形变，图标和文字始终清晰。

展开：先鼓起来，再流开

  • 灵动岛先轻轻鼓一下，像一滴水内部有了压力。
  • 随后向两侧舒展，宽度先到、高度慢半拍，顶部最后才落下，所以是“往下长出来”。
  • 接近目标时略微冲过头，再被表面张力拉回；内容在形状基本展开后才从模糊中浮出。

收起：边缘先回流，最后“咚”一下

  • 内容先淡去，轮廓向摄像头收拢，越接近中心越快，外侧边缘略微滞后。
  • 凝回的瞬间咚：整体轻轻下沉、横向摊开、纵向压扁，回弹一次后停稳，手机上配一下低沉触感。

两滴水之间的让位与挤出

  • 主通知展开后，次通知晚 100ms 被“吸”到摄像头位置补位：沿浅弧线移动，朝中心的一侧先被拉长，途中与主通知之间拉出一道细颈再断开。
  • 主通知回来时先把居中的次通知挤扁，接触瞬间形成连接颈部，越拉越细，啵地断开；次通知滑出去一点再被拉回，约 50ms 后主通知完成“咚”。
